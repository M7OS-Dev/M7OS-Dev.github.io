# 20261122 开发周报：RV64V 屏障开销、缓存排查与镜像内嵌

## 一、fence 代价测试

RT24 线程切换远慢于 K3 大核（同进程单程 9,430 对 464 周期）。用对照探针定位：把同宽
的 `nop` 换成 `fence r,rw`，10,000 轮测相对零条屏障的增量。表内两行是同一探针的两种
计时范围：内核内指能力表查询里那两次依赖读取及其屏障，端到端指完整系统调用往返。

| 计时范围                 | K3 加 1 条 | K3 加 2 条 | RT24 加 1 条 | RT24 加 2 条 |
| ------------------------ | ---------: | ---------: | -----------: | -----------: |
| 内核内：两次读取及屏障   |        +19 |        +29 |         +937 |       +1,526 |
| 端到端：完整系统调用往返 |        +21 |        +43 |       +2,865 |       +3,427 |

K3 只多 19～43 周期，RT24 多出 937～3,427 周期，且增量非线性，说明屏障代价与前后的
访存有关。据此把 `RME_READ_ACQUIRE` / `RME_WRITE_RELEASE` 下移到各芯片头文件，RT24
改用普通读写，K3 与 QEMU 保留 `__ATOMIC_ACQUIRE` / `__ATOMIC_RELEASE`。

改动后（BananaPi-1，10,000 轮，单位 CPU 周期）：

| 线程切换项目    |       K3 大核 |       RT24 原版 |   RT24 当前版 |  降幅 |
| --------------- | ------------: | --------------: | ------------: | ----: |
| `THD_SWT(self)` |     357 / 354 |   5,269 / 5,138 |     471 / 426 | 91.1% |
| 同进程单程      |     464 / 460 |   9,430 / 9,247 |     819 / 815 | 91.3% |
| 同进程往返      |     925 / 912 | 18,810 / 18,467 | 1,632 / 1,625 | 91.3% |
| 跨进程单程      |     548 / 544 |   9,954 / 9,767 | 1,022 / 1,001 | 89.7% |
| 跨进程往返      | 1,074 / 1,069 | 19,207 / 18,851 | 2,013 / 1,977 | 89.5% |

## 二、缓存是否生效测试

怀疑 RT24 的 DDR 绕过了缓存。在 M 态读回 I/D-cache 控制 CSR `0x7c0` / `0x7c1`，再测
同址同负载的开关差异：

| 探针                                      |           开启 |              关闭 |    倍数 |
| ----------------------------------------- | -------------: | ----------------: | ------: |
| I-cache：同址执行 256 条 `nop` 加 `ret`   | 约 265 周期/轮 | 约 20,535 周期/轮 | 77.5 倍 |
| D-cache：8 个相隔 64 字节的节点间依赖读取 | 约 4.6 周期/次 |   约 82.3 周期/次 | 17.8 倍 |

**结论**：I-cache 与 D-cache 都在实际工作，RT24 切换慢不是因为缓存没生效。禁用缓存
不是优化方向。

## 三、init 镜像内嵌进内核镜像

init 原先放在内核镜像预留的固定物理地址，物理地址在芯片头文件和链接脚本里各写一份
常量。本周改为由链接器把 init 排在 `.bss` 之前，三套平台统一处理：新增 `.init_image`
段（紧接已加载段，不再有 4 MB 空洞），`RME_RV64V_INIT_PA` 改由链接符号
`__RME_Init_Image` 推导，不再硬编码。QEMU 侧随之不再需要 `-device loader`。

## 四、删除 satp 相等性检查

`__RME_Pgt_Set` 原先读回 satp 做相等性比较，相等就返回。读 satp 是独立汇编函数
（`CSRRS a0,satp,zero`），每次激活页表都多付一次调用与返回；而不管是否验证相等性，
satp 里最终都会是正确值——命中时本来就对，不命中时会写进去，所以一次读加一次写的
开销大于一次写。

K3 定位实验（临时删掉检查）：

| 指标                      | 带检查 | 删掉检查 | 旧测试结果基线 |
| ------------------------- | -----: | -------: | -------------: |
| `THD_SWT(inter, one-way)` |  566.0 |      546 |            555 |
| `INV_ACT`                 |  528.7 |      510 |            511 |
| `INV_ACT+INV_RET`         |  945.0 |      914 |            930 |

删掉后各项回到基线附近，提升 18～31 周期。正式删除后 `__RME_Pgt_Set` 直接写 satp。
