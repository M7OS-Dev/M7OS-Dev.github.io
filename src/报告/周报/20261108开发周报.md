# 20261108 开发周报：ASID、SBI 与基准测试

## 一、概览

本周主要在 `M7M01_Eukaron`（RME 内核）和 `M7M03_Anomalocaris`（用户态 init
程序）两个仓库工作，主线是补齐 RV64V 端口的 ASID 与 SBI 支持，并把基准测试做全。

## 二、主要工作

### 1. ASID 支持

在 RV64V 端口实现了 ASID：新增 ASID 分配器和 `RME_KFN_PGT_ASID_SET` KFN，给
顶层页表打 ASID 标签，切换时只失效对应 ASID 的 TLB 表项，不再每次切页表都做
全量刷新。配套补上了按 ASID、按虚拟地址刷 TLB 的原语，以及 shutdown 前的
TLB 处理。ASID 0 留给 boot 页表使用。

### 2. SBI 调用统一

把 RV64V 端口对 SBI 的依赖统一到现代 OpenSBI 扩展（TIME、SRST、HSM、DBCN），
并统一了 SBI v0.2+ 的错误码处理，不再依赖隐含约定。

### 3. 基准测试全测

用户态补齐了全部 RV64V SVC 的封装和 KFN 调用入口，基准用例覆盖到 cache 维护、
页表属性查询、调试寄存器读写、异常信息读取等此前无法从用户态验证的能力；内核
侧对应的 cache 维护 KFN 也因此有了可测路径。同时整理了基准框架：去掉
wait quiesce 和线程切换 ticket，简化 rounds，并补上 setup 返回值检查。RV64V
端口的用户程序支持 8 核启动，从核用于验证每个 hart 都能进入用户态。
